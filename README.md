# Alon Moneli’s Portfolio

**Live website:** [alonmoneli.github.io](https://alonmoneli.github.io/)

A software engineering portfolio featuring Python backends, C++ systems, and concurrent software projects.

## How it was built

The site uses HTML, CSS, and vanilla JavaScript. The project descriptions and source links are in [index.html](index.html), and the responsive layout and color themes are in [style.css](style.css).

- The light and dark mode switch follows the browser’s preference by default and remembers your choice in local storage. [theme.js](theme.js)
- The System Monitor demo uses sample CPU readings to show when a sustained spike triggers an alert and when usage returns below the threshold. [monitor.js](monitor.js)

## Preview and deployment

Open `index.html` in a browser to preview the site locally. GitHub Pages serves the static files from the root of the `main` branch.
